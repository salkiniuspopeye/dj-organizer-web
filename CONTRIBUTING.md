# Contributing

We welcome contributions to the DJ Organizer Web App! Please follow these steps to get your development environment set up.

## Development Setup

1.  Clone the repository.
2.  Install the dependencies:
    ```sh
    npm install
    ```
3.  Run the development server:
    ```sh
    npm run dev
    ```

## Running Tests

-   To run the unit tests:
    ```sh
    npm test
    ```
-   To run the end-to-end tests:
    ```sh
    npm run test:e2e
    ```

## Code Style

We use ESLint and Prettier to enforce a consistent code style. Please make sure to run the linter and formatter before submitting a pull request.

-   To lint your code:
    ```sh
    npm run lint
    ```
-   To format your code:
    ```sh
    npm run format
    ```
